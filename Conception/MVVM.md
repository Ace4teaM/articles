# MVVM "Modèle Vue Vue-Modèle"

MVVM est particulièrement adapté aux applications avec interface utilisateur basé sur les binding (états, données). Le programme déclare les propriétés (accesseurs) lié aux éléments de l'interface utilisateur. Les propriétés peuvent fonctionner dans 3 mode (source vers cible, cible vers source ou bidirectionnel)

* Le modèle contient la structure des données métiers

* La vue définit l'interface est les liaisons de propriétés

* Le vue-modèle définit les propriétés sources dans des accesseurs

# MVC "Modèle Vue Contrôleur"

MVC est particulièrement adapté aux applications avec interface utilisateur basé sur les événements (clic, défilement, saisie, ...). Le programme s'abonne aux événements et appelle les méthodes du contrôleur.

* Le modèle contient la structure des données métiers

* La vue définit l'interface est s'abonne aux événements des contrôles

* Le contrôleur déclare les méthodes d'interactions avec le modèle (la logique métier)

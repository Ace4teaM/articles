# R²

Cette méthode d'évaluation est applicable aux modèles de [régression linéaire](RegressionLineaire.md)

> Il explique à quel point le modèle fait mieux que juste prédire la moyenne.

# Quand l'utiliser ?

R² s'utilise en Régression Linéaire et en complément d'autres méthodes d'évaluation tel que [MAE](MAE.md) / [MAPE](MAPE.md) et [MSE](MSE.md) / [RMSE](RMSE.md).

Il permet d'évaluer votre modèle sous un angle différent.

# Exemple

Dans cet exemple d'évaluation du modèle nous obtenons une note de `0.981` ce qui est presque parfais pour un modèle.

```python
# .... Création du modèle et du jeu de test ....

from sklearn.metrics import r2_score

print("R² :", round(r2_score(y_test, y_pred),3), " variation des prix est expliquée par le modèle")
print("1.0   = (bon modèle)           prédictions exactes ")
print("0.0   = (mauvais modèle)       prédictions proche de la moyenne simple ")
print("< 0.0 = (très mauvais modèle)  prédictions pire que la moyenne ")
```

Résultat:

```
R² : 0.981  variation des prix est expliquée par le modèle
1.0   = (bon modèle)           prédictions exactes 
0.0   = (mauvais modèle)       prédictions proche de la moyenne simple 
< 0.0 = (très mauvais modèle)  prédictions pire que la moyenne 
```
